剪掉的内容：说错重说的句子只留后一遍；为了过抖音审核，去掉了顾东政段里「共产主义孩子」那半句（录的时候已当场重说）、「红二代、富二代」那句、结尾「站在山顶……向下面淹死的人说我们是对的」那句（改为以「牢牢抓紧船帆，让自己不掉下去」收尾），吴原同段里小应用「给你算卦」那半句和说排名「都是放屁」那句。台词其余不改字，字幕与原声一致（「牛逼」字幕写作「牛X」，画面上不出现）。

## 第二版改了什么（2026.10.05，按朋友的反馈）

| 反馈 | 改动 |
|---|---|
| 话与话链接有问题 | 57 个剪接点里有 48 个衔接太紧（句号处的停顿中位数只有 0.07 秒），现在每个剪接点都保证自然停顿：句号、问号后 0.5 秒，逗号后 0.3 秒，句中 0.12 秒。 |
| 重复无效的废话需要删除 | 删掉 8 句，2 句只留前半句（重复的「为什么变得那么牛X」「不三不四」、和其他章重复的「走廊」「lecture 老师」，以及「祖国的花朵」等填充句），共约 46 秒。 |
| 画面的过渡有问题 | 以前每次换场景都会先闪一下空白纸面。现在旧画面停到新内容出现前一刻再滑走；换章时整页横向翻过。 |
| 开头要有音效，说到重点要有音乐元素 | 冷开场加了低音冲击、垫底的长音和进片头的渐强。13 处换章有翻页声和两个音的钢琴动机。17 句重点句下面垫了和弦，比人声低约 17 dB，说话时自动压低。全部由片头同一套合成器生成，不涉及版权。 |
| 没有真实的照片呈现 | 13 个场景加了 21 张实景照片和图画：清华、北大、高考考场、苏州、张飞长坂桥（浮世绘）、毕业典礼、美国校车、UCSD、UCSB、NYU、同济、杭州、宁波、UNSW（两张）、帆船（油画）、国内教室、吉隆坡、哈佛、广州贡院号舍、上海证券交易所。张飞、公务员两处拆成了单独的场景。 |
| 有弹幕的问题 | 理解为「满屏都是字」：字幕改成整句直接出现，不再逐字变色；放照片的场景去掉了和口播重复的大字。 |
