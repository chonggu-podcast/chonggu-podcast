# 敢不敢走下坡（模拟退火）

照视频号 trouble1422《年轻时，该不该多折腾？》的形式重做的一条 16:9 视频，58 秒。结构、节奏、画面风格和三种走法的设定跟原片走；口播是重新写的，小人重新画了一个（宽檐帽、提一盏灯，灯的亮度就是“敢走下坡”的温度），所有数字都来自自己跑的模拟。

- 成片：`敢不敢走下坡_16比9.mp4`（1920×1080，30 fps，-14 LUFS，不到 42 MiB，没有拆分）
- 封面：`敢不敢走下坡_封面_3比4.png`（1080×1440）

模拟设定：一条随机生成的山脉，最高点 1000 米，每个人只看得见脚下；上坡一定走，下坡 d 米按概率 exp(-d/T) 走。求稳 T = 0；一直折腾 T 不变；先闯后收 T 从 18 岁按指数下降，35 岁以后为 0。12 座山、每种走法每座山 4000 人，60 岁时平均登顶率：求稳 3.9%、先闯后收 46.7%、一直折腾 12.1%。

模拟、口播、画面和混音的源文件在 `tuihuo` 分支的 `敢不敢走下坡/` 目录。
