# 《重估：“稳定”》（9:16 竖版）

最新版本：**v4**（2026.10.09），1080×1920 60fps，3:59，-14 LUFS。顾东政的一篇独白：伴侣之间的关系会不会长期稳定？离婚对积蓄意味着什么？为什么想要稳定，为什么 30 岁之前只谈恋爱、不结婚，最后落到「扎根」。

**口播与原稿一字不差**（977 字逐字核对过）；中文字幕照原稿，下面加一行小字英文。

**配音由 AI 根据顾东政本人声音合成**（画面开头和片尾字幕都有标注）：用第 4 期录音里他本人的几段原声做参考，在本地用 F5-TTS 克隆；每句按情绪换参考（反问、激动、怀疑、果断、轻松、坚定、平静），合成后用语音识别逐字核对。发到抖音 / 小红书 / 视频号时请勾选「AI 生成内容」声明。

画面（v4）：全片一个镜头到底，没有切换，也没有淡入淡出。金色的点是「我」，走在一片由一天天组成的光点地面上，路一直伸到地平线；左上角的「稳定度」（带一条实时曲线）和右上角的「第 N 天」从头跳到尾。
- 开场无旁白：线冲向地平线、断开，碎屑拼成“稳定”，镜头从字里穿过去，天数倒转回第 1 天。
- 两条线交缠着走，分开时地面裂开，红色波纹扩散到整片地面；金币、旗子、雨滴绕着我转，金币最后转到眼前。
- 起雾 → 镜头转到侧面，地面变成时间轴：头顶一根光柱是我的积蓄，每个月留下一根；离婚时断掉三截，红线从低处再爬。
- 镜头贴着一个月一个月的光柱飞过去，最后拉开，地上标出「≈ 3 年」。
- 光点重新聚成“稳定”，落下来变成台阶，四周长出一座光的城；下一级是闪烁的红色裂纹 → 城碎成灰 → 倒带，我退下台阶，天数回到第 1 天。
- 路分成两条，「爆雷」时另一条路上的光环炸开；路上立着「30 岁」。
- 抬头：星星连成想成为的人，一道光落下来，分成战略、策略、行动。
- 不同颜色的人从身边走过，TA 走过来并肩；调味的光屑，红色的尖刺。
- 雨夜，每一步种下一颗光 → 镜头钻到地底，种子长出发光的根，「扎根」→ 天亮，一棵小树。

这一版是学了几支用 Claude 做、传播很广的短片之后重做的：一个贯穿全片的装置（读数），镜头一直在动，换场靠画面里的东西变形。曲线图是假设情境（图例旁标注）。配乐和音效全部是合成的，没有用外部素材。
