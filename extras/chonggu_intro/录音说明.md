# 《重估》片头：录音说明

画面会自动对齐你们的声音。有两种台词，任选一种。

**四句版**（两人各报名字）：

| 句 | 谁说 | 台词 |
|---|---|---|
| 1 | 原同 | 这里是《重估》，我是原同。 |
| 2 | 东政 | 我是顾东政。 |
| 3 | 两人任选（或一起） | 我们重新审视那些被默认接受的答案。 |
| 4 | 两人任选（或一起） | 今天，我们重估＿＿＿＿。（每期换词） |

**三句版**（不报名字，一个人就能录，生成时加 `--lines 3`）：

| 句 | 谁说 | 台词 |
|---|---|---|
| 1 | 任选（默认原同） | 这里是《重估》。 |
| 2 | 任选 | 我们重新审视那些被默认接受的答案。 |
| 3 | 任选 | 今天，我们重估＿＿＿＿。（每期换词） |

要点：

- 句与句之间留**明显停顿**（0.4–0.8 秒）。句中逗号那里停短一点。程序会按每句的字数判断哪里是换句，句中停顿稍长一点也不会切错。
- 四句版会把句间停顿统一成 0.2–0.3 秒；三句版保留你们自己的停顿（限制在 0.3–0.8 秒之间）。
- 除了最后一句，其余每期都一样，录一次就能一直用；最后一句每期重录。
- 语速自然就好，全部加起来 9–11 秒最合适。
- 录音前后的杂音（手机点击、呼吸）会被自动去掉。
- 手机录音、会议录音都可以，格式不限（m4a / wav / mp3）。

## 生成命令

在 `chonggu_intro` 文件夹里运行。

四句录在一个文件里：

```bash
python3 make_intro.py --topic 青年交流 --episode 2 --date 2026.09.27 --voice 片头录音.m4a
```

前三句和第 4 句分开录：

```bash
python3 make_intro.py --topic 财富 --episode 3 --voice-fixed 前三句.m4a --voice-topic 第四句.m4a
```

三句版（第 2 期实际用的就是这条，片头 700 帧，正好放进顾东政的剪辑流程）：

```bash
python3 make_intro.py --topic 青年交流 --episode 2 --date 2026.09.27 --lines 3 --voice 片头录音.m4a \
    --p3-speaker wu --p4-speaker wu --total-frames 700
```

三句版分开录时，`--voice-fixed` 的文件只有前两句（这里是《重估》+ 我们重新审视……），不能用四句版的「前三句」文件；两段之间的停顿按 0.55 秒算。

- `--topic`：屏幕上显示的主题，2–8 个字最好。太长会被拒绝，这时屏幕上写短一点，嘴上可以念长一点。
- `--date`：录音日期，显示在红点下面，表示「以这一天为准」。可以不写。
- `--lines 3`：三句版。底部的名字和音量条在第 1 句说完时出现；拿四句版的录音配 `--lines 3` 会被拒绝。
- `--p1-speaker`（只用于三句版）/ `--p3-speaker` / `--p4-speaker`：这几句谁说（`wu` / `gu` / `both`），底部的发言人标记会跟着变。第 1 句默认原同，其余默认两人一起。
- `--total-frames`：片头的准确帧数（60 帧/秒），比如 700。程序会调整结尾的停留时间来凑，替代 `--hold`；停留要在 0–5 秒之间，超出会提示可用的范围。
- `--handoff fade|hold`、`--hold`：结尾淡到白纸（默认）还是停在最后一帧，以及停留几秒。
- 不加录音参数：生成只有音乐的版本（没人说话，底部的发言人标记不亮），用来先看画面节奏。

生成的视频在 `outputs/` 文件夹里，旁边的 `.json` 记录了切句的时间（`lines`、`hold` 也在里面；三句版的 `phrases` 里第 2 句是长度为 0 的空位）。如果某个画面没对上字，把 `.json` 发给你的 AI，它可以写一个 `anchors.json` 手动校正（`--anchors anchors.json`）。量时间时，辅音开头的字（zh/ch/sh/x/j/q/s/c）要取辅音的起点，不要取元音；三句版里 `phrases` 写 3 句；主题的最后一个字念完的时间写进 `t_topic_end`，不然红点会提前写完。

录音要先处理（降噪、均衡、去齿音）的话，第 2 期用的处理方法写在 `../work/voice/处理说明.txt`。
