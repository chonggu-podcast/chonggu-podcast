# 声音克隆：给《重估》配音

这里记录我们怎么在 Mac 上本地克隆原同和顾东政的声音，用来给《重估：“稳定”》的两个版本配音：
- 顾东政版（`wending` 分支的 `稳定/`）
- 原同版

用的工具：
- 配音模型：F5-TTS v1，零样本克隆，不需要训练。
- 识别核对：whisper。
- 声纹比对：resemblyzer。

全程在本机跑，不上传到任何服务。

仓库是公开的，所以真人原声不入库。每段参考在第 4 期录音里的起止时间写在 `voice/*.json` 里，用 `cut_refs.py` 可以原样切回来（已核对，和用过的片段完全一致）。

版本历史、实测数据和每一句的情况见 [记录.md](记录.md)。

## 文件

| 文件 | 作用 |
|---|---|
| `tts2.py` | 现在用的合成脚本：按每句的目标语速定时长，多试几条，自动查错，挑最好的一条 |
| `tts.py` | 公用函数（读音处理、按拼音核对、识别、给每个字定时间）；它自己的 `main` 是第一版做法，留作参考 |
| `script.json` | 原同版的完整口播表，每句一行（下面「写 script.json」一节有字段说明） |
| `voice/原同.json` `voice/顾东政.json` | 每种语气一段参考：片段文件名、片段里说的话、在录音里的起止秒数 |
| `cut_refs.py` | 从第 4 期录音切出全部参考片段 |
| `check_voice.py` | 交片前检查：像不像本人、语速、语调起伏、结尾有没有被截 |
| `requirements.txt` | 依赖版本 |

## 一、装环境

```bash
python3.12 -m venv .venv-tts
.venv-tts/bin/pip install -r requirements.txt
```

第一次运行会从 HuggingFace 下载两样东西：
- F5-TTS v1 模型（1.3 GB）；
- whisper-large-v3-turbo（1.6 GB）。

在 M4 MacBook Air 上，每句合成两条、加上识别检查，大约要 1–1.5 分钟，52 句的片子约一小时。合成时会拖慢同时在跑的 Chrome 渲染。

## 二、准备原声

```bash
ffmpeg -i ../work/meeting.mp4 -vn -ac 1 -ar 48000 ../work/src48.wav   # 第 4 期腾讯会议录音 → 48 kHz 单声道
python3 cut_refs.py ../work/src48.wav                                 # → voice/原同/*.wav、voice/顾东政/*.wav
```

`meeting.mp4` 是第 4 期的原始录音，只在本地，没有入库。

## 三、挑参考片段（最影响效果的一步）

参考片段决定了合成出来的声音像不像、有没有起伏。挑新片段时按下面几条来：

1. **5–11 秒，只有一个人在说**：没有笑声、杂音和对方插话，也没有「呃」或说错重来。
2. **两头都落在静音上**：开头前、结尾后各留 0.1–0.3 秒静音，结尾不能截在一个字的中间。
   - 截短了，模型会把缺的那个字补到每句的句尾。原同版的「慢」那段只剪到「清楚」的「清」，结果好几句的结尾都多出一个「楚」。
   - 带上了下一句的开头，模型会把它带到句首。「…就在我自己学的这一行」这段，让好几句开头多出一个「行」。
   - 检查办法：片段最后 50 毫秒应该低于 -40 dB。在原录音里往后看，下一句要真的停顿以后才开始。
3. **`text` 要和片段里说的一字不差**：用 whisper 核对一遍；识别不出最后一个字，通常就是截短了。
4. **按语气多挑几段**：平常、轻松、发问、坚定、慢、意外……都挑本人说话起伏大的地方。只用一段平静的参考，整片会平得让人犯困。原同版第一版就是这个问题，原同的评价是「语调太平，昏昏欲睡」。

## 四、写 script.json

```json
{
 "refs": "voice/原同.json",
 "gap": 0.45,
 "lines": [
  {"id": "e3", "text": "人是动物。", "tts": "人是动物！", "mood": "firm", "rate": 4.0, "gap": 0.9},
  ...
 ]
}
```

| 字段 | 意思 |
|---|---|
| `text` | 字幕。必须和原稿一字不差 |
| `tts` | 只给模型看的写法，用来修读音、加强语气（可省略，省略就用 `text`） |
| `mood` | 用哪段参考（`voice/*.json` 里的键） |
| `rate` | 目标语速，单位是字/秒：重点句、反问 4.0–4.4，平常 4.6–4.9，举例、列举 5.0–5.4。原同平时说话约 4.8 |
| `gap` | 这句之后停多久（秒） |

`tts` 字段里用过的读音处理：

| 字幕 | 给模型的写法 | 为什么 |
|---|---|---|
| 这个 | 这各 | 「个」会被读成很短的轻声，听着像被吞掉 |
| 重估 | 虫估 | 「重」会被读成 zhòng |
| 得靠自己 | Ⓓ靠自己 | 「得」要读 děi；`tts.py` 把 Ⓓ 换成拼音 dei3 |
| 差不多 / 意思是 | 差布多 / 意丝是 | 原来的写法会吞掉中间的字 |
| 看得见 | 看的见 | 「得」被读重 |
| 11 月 / 30 岁 | 十一月 / 三十岁 | 数字要写成汉字 |
| ——、： | ，  | 让模型停顿 |
| 人是动物。 | 人是动物！ | 要强调的句子用感叹号 |

## 五、合成

```bash
.venv-tts/bin/python tts2.py                                # 只重做文字、参考或语速改过的句子
.venv-tts/bin/python tts2.py --redo b6,e3 --seeds 37,59     # 对这几句再多试两条，已有的那条一起比
```

每一句的流程：

1. **定时长**：按目标语速算出时长交给模型（F5 的 `fix_duration`）。差了 10% 以上就按实际语速再算一次。
2. **两个随机种子各合成一条**，切掉首尾静音。
3. **查句首**：识别出开头有稿子里没有的字（参考结尾带进来的），就在停顿处切掉。
4. **查全句**：按不带声调的拼音和稿子比，同音字不算错。
5. **查句尾**：把最后 0.9 秒单独拿去识别。整句识别时，识别器经常把句尾多出来的那个轻音节漏掉，单独听才抓得到。
6. **挑一条**：
   - 先看识别是否一字不差；
   - 再看句尾干净；
   - 再看语速在目标 ±10% 以内；
   - 最后挑音高起伏最大的。

输出：
- `audio/line_XX.wav`：48 kHz 单声道；
- `data/asr.json`：每句的识别结果、语速、起伏、用的种子；
- `data/timeline.json`：每句和每个字在片子里的时间，画面和字幕用它对齐。

注意：缓存只认参考片段的文件名和文字，不认里面的声音。重剪了参考片段以后，要把用到它的句子从 `data/asr.json` 里删掉，它们才会重做。

## 六、交片前检查

```bash
.venv-tts/bin/python check_voice.py voice/原同.json ../work/src48.wav
```

1. **识别对不上的句子**（`cer` 大于 0）：换个提示词再识别一遍。识别器的习惯不算错，比如原同版里：
   - 「岗位照招」被识别成「照着」；
   - 「线变平了」被识别成「变频」；
   - 静音里冒出「Ｂ」「７」。
2. **句尾多字**：标了 `EXTRA AT END` 的句子要重做。用了同一段参考的其他句子，也要人耳听一遍。
3. **语速**：重点句应该明显比举例慢。原同版第一版这两类几乎一样快（都约 5.3 字/秒），听感就是「该慢的快了」。
4. **语调**：用音高起伏衡量，即半音标准差。原同真人说话的中位数约 4.3，低于 3 的句子听着就平。
5. **结尾被截**：标了 `CUT OFF` 的句子尾音被切了，是模型给的时长不够。重做，或在最后 40 毫秒加淡出（时长不变，画面不用重渲）。
6. **像不像**：和本人参考片段的相似度。原同版平均 0.90；原同本人另外几段话是 0.97，顾东政是 0.68。不到 1 秒的短句测不准。
7. **通篇听一遍**：上面这些都过了，原同还是听出了句尾的「楚」。最后一关只能靠人耳。

## 七、常见问题

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 句首多出「行」「明白」 | 参考片段结尾带进了下一句的开头 | `tts2.py` 自动切掉；常出现就重剪参考 |
| 句尾多出「楚」之类的音 | 参考片段截在一个字中间 | 重剪参考，删缓存，用到它的句子重做 |
| 吞字、读错 | 模型的拼音前端 | 在 `tts` 里换同音字，见上表 |
| 太快或太慢 | 句子太短（6 个字以内）时长不好控 | 调 `rate` 重做；短句可以用 `ffmpeg -af atempo=0.88` 放慢，不变调 |
| 太平 | 参考片段本身平 | 换起伏大的参考，`--redo` 多试几条 |
| 尾音被截 | 给的时长不够 | 重做，或在最后 40 毫秒加淡出 |

## 八、规矩

- 口播必须和原稿一字不差；要改读音只能改 `tts` 字段，字幕不动。
- 真人原声（`voice/**/*.wav`）不入库，只记录在录音里的位置。
- 只用两位主持人自己的声音，只用在《重估》里。
- 是否在片中标注：顾东政版在开头和片尾字幕标了「配音由 AI 根据顾东政本人声音合成」；原同版按原同的要求，片中不提。
